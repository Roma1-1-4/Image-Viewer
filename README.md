# Image-Viewer

##### A local image viewer that runs in the Chrome browser



A lightweight image viewer that makes viewing images convenient. It runs directly within the Chrome browser, operating entirely locally on your PC. This viewer is designed to handle a large number of images at once—you can even browse folders containing 10,000+ images! It is highly optimized and consumes minimal system resources.



##### How to use:

1. Click “Select folder” and allow the browser to read the folder.

2\. The application will recursively find supported images: .png, .jpg, .jpeg, .webp, .avif, .bmp and display them in a grid with thumbnails.

3\. Click on a file to open it in the viewer.

4\. Scroll through images using the arrow keys, zoom in with the mouse wheel, and drag the image when zoomed in.



###### Hotkeys

Key	Action

← / →	Previous / next image

F	Full screen / exit full screen

R	Refresh file list

I	File information

\+ / -	Zoom in / zoom out

0	Reset zoom and position

Esc	Close view or help

F1	Show / close this help



###### Functions

* Formats — PNG, JPEG, WebP, AVIF, BMP are supported.
* Search — instantly filters files by name. Works on all found images, including subfolders.
* Sorting — “By name”, “By modification date”, or “By size”. Natural sorting is used for numbers in file names.
* Auto‑update — periodically rescans the folder and shows new/changed files. The interval automatically increases with the number of files to avoid overloading the system.
* Update — manual rescan of the folder without changing the search and sorting.
* All operations are performed locally in the browser. The images are not uploaded to the server and do not leave the device.







##### Локальный просмоторщик изображений

Лёгкий просмоторщик изображений позволяет удобно просматривать изображения. Он работает прямо в браузере Chrome, полностью локально у Вас на ПК. Этот просмоторщик рассчитан на работу со множеством изображений сразу. Можно просматривать папки с 10000+ изображений! Просмоторщик оптимизирован, потребляет минимум ресурсов.



1. Нажмите «Выбрать папку» и разрешите браузеру чтение папки.

2\. Приложение рекурсивно найдёт поддерживаемые изображения: .png, .jpg, .jpeg, .webp, .avif, .bmp и покажет их в сетке с миниатюрами.

3\. Кликните по файлу, чтобы открыть его в просмотрщике.

4\. Листайте изображения стрелками, зумьте колесом мыши и перетаскивайте картинку при увеличении.

###### Функции

* Форматы — поддерживаются PNG, JPEG, WebP, AVIF, BMP.
* Поиск — мгновенно фильтрует файлы по имени. Работает по всем найденным изображениям, включая подпапки.
* Сортировка — «По имени», «По дате изменения» или «По размеру». Для чисел в именах используется естественная сортировка.
* Автообновление — периодически пересканирует папку и показывает новые/изменённые файлы. Интервал автоматически растёт с количеством файлов, чтобы не нагружать систему.
* Обновить — ручной перескан папки без изменения поиска и сортировки.
* Все операции выполняются локально в браузере. Изображения не загружаются на сервер и не покидают устройство.
